# Md-table-kit

Convert spreadsheet cells and TSV text into perfectly aligned GitHub markdown tables offline.

Web app: **[cig13zs.github.io/md-table-kit](https://cig13zs.github.io/md-table-kit/)**

## What it does

Runs 100% offline in your browser. Zero tracking, zero network requests.

## Install

1. Download latest zip from [Releases](https://github.com/cig13zs/md-table-kit/releases).
2. Open chrome://extensions and turn on **Developer mode**.
3. Click **Load unpacked** and select extension.
